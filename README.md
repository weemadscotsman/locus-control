# Locus Control

> A React-based control interface application.

## Overview

Locus Control is a web application built with React and TypeScript, featuring a modular architecture with separate backend integration, contexts, hooks, and services.

## Project Structure

```
locus-control/
├── backend/          # Backend integration
├── components/       # React components
├── contexts/         # React contexts
├── hooks/            # Custom React hooks
├── services/         # Service layer
├── utils/            # Utility functions
├── App.tsx           # Main application component
└── index.tsx         # Application entry point
```

## Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** CSS/Tailwind
- **State Management:** React Context
- **Backend:** API integration layer

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## Features

- Modular component architecture
- Custom hooks for state management
- Service layer for API integration
- Context providers for global state

## Development

```bash
# Run tests
npm test

# Lint code
npm run lint
```
